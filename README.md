# MILO CASHIER — لوحة الإدارة عبر CSV

## التشغيل
1. شغّل الموقع باستخدام خادم ثابت (مثل استضافة GitHub Pages أو `python -m http.server 8000` ثم فتح `http://localhost:8000`).
2. أول فتح: أنشئ اسم مستخدم وكلمة مرور من 8 أحرف على الأقل. هذه **حماية محلية شكلية وليست تسجيل الدخول الأصلي للكاشير**.
3. يعرض الموقع CSV الرئيسي المنشور مسبقًا تلقائيًا، ويمكن تعديل روابط CSV في الإعدادات.
4. لرؤية كل الأقسام، انشر كل ورقة بيانات في Google Sheets كـ CSV مستقل، ثم ضع رابطها أمام القسم المقابل.
5. جرب الفلاتر الزمنية والتحديث وتصدير البيانات.

## مهم
- الرابط الواحد (`pub?output=csv`) يعرض **ورقة واحدة** ولا يسمح بالوصول لجميع أوراق الملف/حساب الكاشير تلقائيًا.
- الأعمدة المحتملة للفواتير: رقم الفاتورة، التاريخ، الإجمالي، الحالة، طريقة الدفع. يمكن استخدام المقابلات الإنجليزية أيضًا (invoiceNumber, date, total, status, paymentMethod).
- لحماية بيانات الحساب، لا تنشر CSV يحتوي على أرقام جوال أو حسابات أو معلومات حساسة. كل من لديه رابط CSV المنشور قد يتمكن من قراءته حتى دون تسجيل الدخول للموقع.
- لكي تعمل **نفس بيانات دخول الكاشير الحقيقية** ويكون **لكل حساب بياناته وحده**، يلزم API مع مصادقة آمنة وتصريح صلاحيات على الخادم. لا يمكن عمل ذلك بأمان من CSV العام وحده.
- صافي المبيعات المعروض = مجموع الفواتير غير الملغاة - المصروفات المسجلة؛ ليس احتسابًا محاسبيًا كاملاً للضريبة والمرتجعات والتكاليف.
- لا تُرسل كلمة المرور إلى مصدر CSV، ويتم حفظ بصمتها محليًا في المتصفح فقط. لا يصلح هذا كحماية إنتاجية.

## الملفات
- `index.html`: الواجهة
- `styles.css`: التصميم
- `app.js`: التشغيل وجلب CSV والرسوم والتقارير
- `config.js`: عناوين CSV والإعدادات الأولية
